## 技术细节

### 状态管理
- 使用 `activeNav` 跟踪当前激活的一级导航
- 使用 `selectedPlatform` 跟踪选品模块选择的平台
- 使用 `secondaryNavCollapsed` 控制二级导航折叠状态

### 路由监听
- 通过 `watch` 监听路由变化，自动设置激活的导航
- 根据路由路径自动识别应该激活的一级导航和平台

### 组件复用
- 使用 `component :is` 动态加载二级导航组件
- 通过 computed 属性计算当前应该显示的组件
