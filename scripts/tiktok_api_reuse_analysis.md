## 2. 交互与状态流转说明

### 2.1 侧边栏手风琴展开/收起的触发条件与交互规则

```
用户操作流程:
┌─────────────────────────────────────────────────────────────┐
│ 1. 用户点击一级菜单项（如"商品"）                              │
│    ↓                                                         │
│ 2. 触发 handleMenuSelect(index)                              │
│    ↓                                                         │
│ 3. Element Plus Menu组件检查 :unique-opened="true"           │
│    ↓                                                         │
│ 4. 自动收起其他已展开的一级菜单                                │
│    ↓                                                         │
│ 5. 展开当前点击的菜单，显示二级菜单项                          │
│    ↓                                                         │
│ 6. 用户点击二级菜单项（如"商品搜索"）                          │
│    ↓                                                         │
│ 7. 触发路由跳转: router.push('/tiktok/products/search')      │
│    ↓                                                         │
│ 8. 加载对应页面组件，调用API获取数据                           │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 路由跳转时的加载状态、高亮同步机制、异常拦截策略

```
状态管理流程:
┌─────────────────────────────────────────────────────────────┐
│ 路由跳转前 (beforeEach)                                       │
│ ├─ 检查用户登录状态                                           │
│ ├─ 检查权限要求                                               │
│ └─ 显示全局Loading                                            │
│                                                              │
│ 路由跳转中                                                    │
│ ├─ 更新 activeMenu 状态                                      │
│ ├─ 高亮当前菜单项                                             │
│ └─ 组件开始加载                                               │
│                                                              │
│ 组件挂载后 (onMounted)                                        │
│ ├─ 调用对应API接口                                            │
│ ├─ 显示局部Loading                                            │
│ └─ 处理响应数据                                               │
│                                                              │
│ 数据加载完成                                                  │
│ ├─ 隐藏Loading                                               │
│ ├─ 渲染数据到页面                                             │
│ └─ 更新面包屑导航                                             │
│                                                              │
│ 异常处理                                                      │
│ ├─ 401: 跳转登录页                                           │
│ ├─ 403: 提示权限不足                                          │
│ ├─ 404: 提示接口不存在                                        │
│ ├─ 500: 提示服务器错误                                        │
│ └─ 网络错误: 提示网络异常，可重试                              │
└─────────────────────────────────────────────────────────────┘
```

```
导航联动机制:
```

## 3. 潜在冲突与风险清单

### 3.1 技术风险

| 风险类型 | 具体描述 | 影响范围 | 规避方案 | 回滚预案 |
|---------|---------|---------|---------|---------|
| 路由冲突 | TikTok路由与独立站路由命名冲突 | 前端路由系统 | 使用`/tiktok`前缀隔离 | 回退到独立路由配置 |
| API路径重复 | 新建API与现有API路径重复 | 后端接口 | 严格遵循命名规范，添加`tk_`前缀 | 删除冲突接口，使用临时路径 |
| 状态管理冲突 | 多个导航状态互相干扰 | 全局状态 | 使用独立的state命名空间 | 清空localStorage重置状态 |
| 缓存未更新 | 前端缓存导致新功能不生效 | 用户体验 | 版本号控制，强制刷新 | 清除浏览器缓存 |
| 权限越权 | 用户访问未授权的TikTok功能 | 安全性 | 前后端双重权限校验 | 临时关闭功能入口 |

### 3.2 业务风险

| 风险类型 | 具体描述 | 影响范围 | 规避方案 | 回滚预案 |
|---------|---------|---------|---------|---------|
| 数据源缺失 | TikTok数据接口未就绪 | 功能可用性 | 使用Mock数据占位 | 隐藏未就绪功能 |
| 接口超时 | TikTok API响应慢，用户体验差 | 用户体验 | 设置合理超时时间，显示加载状态 | 降级到缓存数据 |
| 多端适配错位 | 移动端显示TikTok侧边栏错乱 | 移动端用户 | 响应式设计，小屏隐藏侧边栏 | 禁用移动端TikTok功能 |
| 权限配置错误 | 普通用户看到管理员功能 | 安全性 | 严格的权限配置审查 | 紧急下线功能 |
| 接口重复定义 | 前后端对接口理解不一致 | 开发效率 | 使用Swagger文档对齐 | 召开技术对齐会议 |
