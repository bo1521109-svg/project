# 全局布局重构计划

## 需求概述
将当前的"横向一级导航 + 左侧图标栏"布局改为"纵向一级导航 + 二级导航"的统一左侧边栏布局。

## 当前架构
```
顶部横向一级导航栏：
TikTok热榜 | 独立站数据 | 内容创作 | 资源管理 | 出海生态 | 平台管理

左侧图标栏（60px）：
点击图标 → 弹出对应平台的二级菜单
```

## 一级导航映射关系

| 新一级导航 | 原横向导航 | 说明 |
|-----------|-----------|------|
| 选品（带下拉）| TikTok热榜 + 独立站数据 | 通过下拉选择切换TikTok/独立站的二级菜单 |
| 创作 | 内容创作 | 直接映射 |
| 社媒 | 社媒管理 | 直接映射 |
| 建站 | （新增） | 需要确认内容 |
| 客资 | （新增） | 需要确认内容 |
| 出海 | 出海生态 | 直接映射 |
| 平台 | 平台管理 | 直接映射 |

## 关键特性

1. **左侧一级导航**
   - 宽度：60-80px
   - 显示：图标 + 文字
   - 固定显示，不可折叠

2. **右侧二级导航**
   - 宽度：200-250px
   - 内容：根据选中的一级导航动态切换
   - 可展开/收起的树形菜单

3. **选品特殊逻辑**
   - 只有"选品"有下拉选择（TikTok/独立站）
   - 选择TikTok：显示TikTok的二级导航（原TikTok sidebar内容）
   - 选择独立站：显示Shopify的二级导航（原Shopify sidebar内容）

4. **保持不变的部分**
   - 所有路由路径保持不变
   - 所有页面组件保持不变
   - 所有后端API保持不变
   - 只改变布局和导航方式

## 需要修改的文件

### 新建文件
1. `frontend/src/layout/VerticalLayout.vue` - 新的纵向布局组件
2. `frontend/src/components/VerticalSidebar.vue` - 统一的左侧边栏组件

### 修改文件
1. `frontend/src/config/navigation.js` - 重构导航配置
2. `frontend/src/main.js` 或 `frontend/src/App.vue` - 切换到新布局
3. `frontend/src/router/index.js` - 可能需要调整布局引用

### 保持不变
- 所有 `views/*` 页面组件
- 所有 `components/TikTok/sidebar.vue` 等侧边栏组件（作为二级导航内容复用）
- 所有后端 API 文件
