# 纵向布局测试指南

## 启动开发服务器

```bash
cd Myproject/frontend
npm run dev
```

## 测试步骤

### 1. 登录测试
1. 访问 `http://localhost:5173/login`
2. 使用测试账号登录
3. 验证登录后跳转到首页

### 2. 布局检查
1. 检查左侧一级导航是否显示
2. 检查右侧二级导航是否显示
3. 检查主内容区域是否正常

### 3. 一级导航测试
点击每个一级导航项，验证：
- [ ] 选品 - 显示平台选择器和对应侧边栏
- [ ] 创作 - 显示内容创作侧边栏
- [ ] 社媒 - 显示社媒管理侧边栏
- [ ] 建站 - 禁用状态（灰色）
- [ ] 客资 - 禁用状态（灰色）
- [ ] 出海 - 跳转到出海生态页面
- [ ] 平台 - 仅管理员可见，显示管理员侧边栏

### 4. 选品模块平台切换测试
1. 点击"选品"导航
2. 在平台选择器中选择"TikTok"
   - 验证显示 TikTok 侧边栏
   - 验证路由跳转到 TikTok 相关页面
3. 在平台选择器中选择"独立站"
   - 验证显示 Shopify 侧边栏
   - 验证路由跳转到 Shopify 相关页面

### 5. 二级导航测试
在每个模块的二级导航中：
1. 点击各个菜单项
2. 验证路由正确跳转
3. 验证页面内容正确显示

### 6. 二级导航折叠测试
1. 点击二级导航右侧的折叠按钮
2. 验证二级导航收起
3. 验证主内容区域宽度自动调整
4. 再次点击展开按钮
5. 验证二级导航展开

### 7. 路由自动识别测试
1. 直接在浏览器地址栏输入路由路径
2. 验证一级导航自动激活正确的项
3. 验证二级导航自动显示对应的侧边栏

测试路径示例：
- `/tiktok/category/overview` - 应激活"选品"，显示 TikTok 侧边栏
- `/shopify/stores/search` - 应激活"选品"，显示 Shopify 侧边栏
- `/content/workbench` - 应激活"创作"，显示内容创作侧边栏
- `/social/workbench` - 应激活"社媒"，显示社媒管理侧边栏
- `/admin/users` - 应激活"平台"，显示管理员侧边栏

### 8. 权限测试
1. 使用普通用户登录
   - 验证看不到"平台"导航
   - 验证无法访问 `/admin/*` 路径
2. 使用管理员账号登录
   - 验证可以看到"平台"导航
   - 验证可以访问 `/admin/*` 路径

### 9. 退出登录测试
1. 点击左侧导航底部的"退出"按钮
2. 验证跳转到登录页
3. 验证 token 已清除
4. 验证无法访问需要登录的页面

## 常见问题

### 问题1：二级导航不显示
- 检查是否正确导入了侧边栏组件
- 检查 `currentSecondaryNav` computed 是否返回正确的组件

### 问题2：路由跳转不正确
- 检查路由配置是否正确
- 检查侧边栏组件中的路由路径是否正确

### 问题3：平台切换不生效
- 检查 `selectedPlatform` 状态是否正确更新
- 检查 `handlePlatformChange` 方法是否正确执行

### 问题4：权限控制不生效
- 检查 user store 中的 role 属性是否正确
- 检查路由守卫是否正确配置
