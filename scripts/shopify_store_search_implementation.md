# Shopify 店铺搜索页面实现总结

## 概述
本次开发实现了 Shopify 店铺搜索页面的完整前端界面，包括搜索框、多级筛选功能和类目下拉菜单系统。

## 主要文件
- `frontend/src/views/shopify/StoreSearch.vue` - 店铺搜索页面主文件

## 功能实现

### 1. 搜索框设计
- 圆形输入框设计，放大镜图标位于输入框内部右侧（suffix位置）
- 放大镜可点击触发搜索
- 搜索框居左对齐
- 蓝紫色渐变主题（#7c4dff → #9b7ff7）
- 支持回车键搜索

### 3. 类目下拉菜单系统（技术亮点）

#### 3.1 实现方案
- 使用 Vue Teleport 将下拉菜单渲染到 body 层级
- 鼠标悬浮触发（不是点击）
- 使用 position: fixed 和 JavaScript 动态计算位置
- 避免被父容器的 overflow: hidden 限制

#### 3.2 样式设计
- 下拉菜单宽度：160-180px
- 最大高度：200px（精确显示5个完整项目）
- 超出内容通过滚动查看
- 自定义滚动条样式（6px宽度，圆角设计）
- 白色背景，圆角12px
- 阴影效果：0 4px 20px rgba(0, 0, 0, 0.15)

#### 3.3 交互逻辑
- 鼠标悬浮在类目按钮上显示下拉菜单
- 鼠标移动到下拉菜单上保持显示
- 鼠标离开后100ms延迟关闭
- 点击子类目后自动关闭下拉菜单
- 选中的子类目高亮显示（蓝紫色渐变背景）

### 4. 展开/收起功能

#### 4.1 国家/地区和类目支持展开/收起
- 折叠状态：单行显示（max-height: 38px, overflow: hidden）
- 展开状态：多行显示
- 动态检测内容是否溢出
- 只有溢出时才显示"展开/收起"按钮
- 渐变遮罩效果让折叠更自然

#### 4.2 展开/收起按钮
- 可以换行到第二行
- 蓝紫色文字（#7c4dff）
- 带有上下箭头图标

### 5. 按钮样式系统

#### 5.1 未选中状态
- 透明背景
- 黑色文字（#000）
- 圆角：20px
- 字体大小：15px
- 内边距：8px 16px

#### 5.2 选中状态
- 蓝紫色渐变背景（linear-gradient(135deg, #7c4dff 0%, #9b7ff7 100%)）
- 白色文字
- 圆角：20px

#### 5.3 Hover效果
- 浅灰色背景（#f5f5f5）
- 向上平移2px（transform: translateY(-2px)）

### 6. 筛选标签样式
- 黑色粗体（font-weight: 600）
- 最小宽度：100px
- 与筛选内容对齐

## 技术细节

### 1. 响应式设计
- 大屏（≥1200px）：横向布局
- 小屏（<1200px）：纵向布局
- 移动端（<768px）：优化的紧凑布局

### 2. 性能优化
- 使用 nextTick 确保 DOM 更新后再检测溢出
- 监听窗口大小变化，动态调整展开/收起按钮显示
- 下拉菜单使用 fixed 定位，避免重排

### 3. 用户体验优化
- 搜索框支持回车键搜索
- 放大镜图标可点击
- 下拉菜单鼠标悬浮触发，操作流畅
- 折叠状态下的渐变遮罩效果
- 自定义滚动条样式
