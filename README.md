# Myproject - 跨境电商独立站数据平台
时间2026/4/2 测试

## 项目说明
基于 Python 3.11、FastAPI、PostgreSQL 15 的 Docker 化应用（第一期 MVP）

## 快速启动

### 1. 进入项目目录
```bash
cd Myproject
```

### 2. 启动 Docker Desktop

### 3. 构建并启动服务
```bash
docker-compose up --build
```

### 4. 访问应用
- API 根路径: http://localhost:8000
- 交互式文档: http://localhost:8000/docs
- PostgreSQL: localhost:5432

### 5. 停止服务
```bash
docker-compose down
```
